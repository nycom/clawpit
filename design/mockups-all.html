Code tab: the panel, the Agents pane and the file tree, together

One window per view, dark then light. Click the top-right icon to step the panel's size, the tabs to switch panes, and a row to open its log. Add ?theme=dark or ?theme=light to show one theme. The session column opens the cost list; a chip or the folded agents column opens the Agents pane. States: needs you (with one background shell), failed, failed and needs you together, the cost list, no agents yet, a plan from a file, a plan ticked out of order, the session needs you, the session needs you above the crew, a one-time setup question, a setup question over running agents, background work alone, background work beside the crew.
